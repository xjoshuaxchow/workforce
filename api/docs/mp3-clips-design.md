# 預錄片段電話

新增自備 MP3／PCM WAV 模式，保留現有 Say 設定及所有舊通知快照。預設仍是 Say，管理員自行切換，沒有自動 TTS 後備。通用稱呼不讀員工姓名，非空補充說明必須有對應員工語言的調度錄音。

錄音庫按語言對應固定提示、年份數字、年單位、月份、日期、小時、分鐘、UTC 時差及 Site 名稱地址。錄音範例明確標示每片段需要包含的單位。使用 Site 時區組合開始及結束的完整日期時間；英語用日期、月份、年份順序。Twilio Gather 內依序 Play 各片段，不要求 ffmpeg，不做二進位 MP3 串接。片段間可能有短暫停頓，AMS 可以逐段或連續試聽。

Site 錄音鍵包含名稱、地址、時區摘要，資料變更後需要重新配對。存檔只驗證已配對的檔案，不要求一次錄齊。發佈預檢涵蓋合資格候選人及確認／取消／額滿跟進，缺漏顯示清單並保留草稿。錄音資產不可覆寫，已發出工作用原版本及原檔，封存不能破壞歷史播放。

新增調度 voice-preview 只讀 API 供 Site 授權使用者預檢及試聽，不撥電話。調度補充錄音限草稿可改。公開播放使用現有不透明 token；控制台試聽使用同來源 media URL，不回傳憑證。
