# PSTN 測試清單

2026-11-03。這份清單補充既有 Workforce 驗收表。所有真機案例目前為「未執行」，不要把 fake client 的通過視為真機通過。

## 已有自動化範圍

- SDK 設定、TwiML 跳脫、DTMF 1／2／9、狀態映射、公開 URL 與全欄位簽章、Calls 參數。
- 真 Postgres + fake Calls：單次提交、重跑工作不重撥、錯誤簽章／Call SID／電話拒絕、重複與錯序回調、同時搶最後名額、未接／無按鍵。
- timeout／503 結果不明不重撥、429 安全重試、400 永久失敗、回調早於 REST 回傳、未知 SID 恢復與取消意圖。
- Request 取消時取消可取消電話；接單確認等待原電話結束；通知電話完成；回調持久狀態與 inbox 之間中斷後的重送恢復。
- 429 重試時手機／主叫號碼更新、非阻塞回調、提交時間與 job lease 不同時的恢復、舊模式寫入無業務／Audit 副作用。
- 啟動缺必要設定提早失敗；AMS 明示 mock／真實 PSTN 並只在 mock 顯示模擬回覆工具。
