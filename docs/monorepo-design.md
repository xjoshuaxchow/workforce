# 單一 Git 整合設計

使用者已確認以一個 Git 管理 ams、api、whatsapp-microservice，並指定遠端 git@github.com:xjoshuaxchow/workforce.git。目的為統一取回原始碼、維護與後續部署。

在新目錄建立獨立 repository，匯入三個來源的 Git 非忽略原始檔；保留舊目錄與現有服務，不將嵌套 .git、私有環境設定、執行資料、模型或生成音檔提交。三個服務保留各自 package-lock 與執行邊界，調整跨專案預設路徑。根目錄提供安裝、建置、驗證入口與部署現況說明，並保存微服務上游提交標記。

已討論另一個方案為三個獨立 Git，適用不同維護團隊或共享微服務；本次按使用者選擇整合為單一 Git。完整的伺服器部署檔需按主機、網域及 CPU 另行配置，此次不宣稱已部署。

驗證原始匯入內容一致、微服務上游檔案完整、私有檔案忽略規則、AMS/API 測試路徑、單元測試與建置、隔離資料庫整合/瀏覽器測試。完成一次獨立審查後，按使用者指定遠端發佈首次 main 分支，不覆寫任何既有遠端分支。
